# Daily log

Monthly journal templates generated by the [Daily Log workflow](.github/workflows/daily-log.yml).

## Using the journal

1. Open the current month in [journal/](journal/), using the `YYYY-MM.md` filename.
2. Find today's heading and replace the two prompts with what you learned or worked on and one improvement for tomorrow.
3. Mark the checkboxes when you have completed the reflection.

The workflow creates the dated heading and blank prompts. An automatically generated entry does not mean the reflection has been filled in.

## Automation

- The schedule is `0 23 * * *`: 23:00 UTC, or 06:00 WIB the following day. Scheduled runs can be delayed.
- Dates and monthly filenames use `Asia/Jakarta`.
- If today's heading already exists, the workflow skips adding it again.
- A new monthly file is created when needed.
- To run it manually, open **Actions → Daily Log → Run workflow**.

If an entry is missing, inspect that workflow's run log. It needs repository contents write permission to commit the journal update. Check the existing month file before triggering another run.
